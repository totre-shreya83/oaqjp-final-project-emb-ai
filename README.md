# Emotion Detection Application

## Project Description
This project uses IBM Watson Natural Language Processing (NLP) to analyze text and identify emotions.

## Features
- Detects anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Provides a Flask web interface.
- Includes error handling and unit tests.
- Uses Pylint for static code analysis.

## Technologies
Python, IBM Watson NLP, Flask, unittest, and Pylint.
